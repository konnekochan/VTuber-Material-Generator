Aqua Material Generator

【このツールでできること】
ブラウザ上で、OBSに読み込める配信素材を作成できます。
・テロップ、タイトル、お知らせ、SNS表示、待機画面など12種類の素材
・文字の色・サイズ・縁取り・グラデーション、背景の色・濃度を調整
・表示アニメーション、繰り返し表示、ランダムメッセージの設定
・画像スライドショーの追加・並べ替え・削除・切り抜き

【使い方】
1. index.htmlをブラウザで開き、素材を選んで設定します。
2. 「OBS用に書き出し」でHTMLファイルを保存します。
3. OBSの「ブラウザ」ソースで「ローカルファイル」にチェックし、保存したHTMLを選びます。
詳しい手順は、ツール内の「使い方」タブをご覧ください。

【画像の取り扱い】
選択した画像は、お使いのブラウザ内で処理されます。
このツールから外部へ送信・アップロードされることはなく、AIの学習にも使用されません。
画像の処理はローカル環境で完結します。

OBS用に書き出すと、画像はHTMLファイル内に保存されます。
画像を含むため、ファイルを共有する際はご注意ください。
